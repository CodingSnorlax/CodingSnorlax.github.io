解決 img 空隙的三種方法
Karen Huang
  2022-01-07 15:24:44 2022-01-07 15:24  
  • CSS 
  • > 排版常見問題 
 
  • CSS 

(一) 轉區塊元素

img 是 inline 元素，因此 img 會出現上述提到的空隙問題，
但如果將 img 轉為 block 元素，性質轉變了，空隙問題也就消失了。


(二) 調整 text-align

同樣利用 img 的 inline 元素特性，
在 text-align 更改它的對齊方向：

  • top
  • bottom
  • text-top
  • text-bottom

(三) font-size 歸零

一樣是因為 img 的 inline 元素特性，
但這次是在 img 的父層設定 inline 元素的 font-size 大小，
將 font-size 歸零，也可消除空隙。
